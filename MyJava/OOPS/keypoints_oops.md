/**
 * KEY INTERVIEW POINTS TO REMEMBER:
 * 
 * 1. ENCAPSULATION:
 *    - Data hiding using private access modifiers
 *    - Controlled access through public methods
 *    - Protects data integrity
 * 
 * 2. INHERITANCE:
 *    - Code reusability through IS-A relationship
 *    - super keyword to access parent class members
 *    - Constructor chaining
 * 
 * 3. POLYMORPHISM:
 *    - Compile-time: Method overloading for example same function name but different arguments, as display(int num) and display(double num)
 *    - Runtime: Method overriding, for example: start() method in Vehicle class is overridden in Car class
 *    - Same interface, different implementations
 * 
 * 4. ABSTRACTION:
 *    - Abstract classes: Can have both abstract and concrete methods
 *    - Interfaces: All methods are abstract (except default/static in Java 8+)
 *    - Cannot instantiate abstract classes or interfaces directly
 * 
 * 5. INTERFACE vs ABSTRACT CLASS:
 *    - Interface: Multiple inheritance, all methods public
 *    - Abstract class: Single inheritance, can have constructors
 *    - Use interface for contracts, abstract class for common behavior
 */
